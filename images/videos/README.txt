Put short animated video ad samples in this folder using these names:

video-01.gif
video-02.gif
video-03.gif

The site checks video-01 through video-80 automatically.
Supported format is gif.

The first 4 GIFs are shown immediately.
If there are more than 4 GIFs, a View all videos button appears.
The button changes to Show less videos after opening the full list.
