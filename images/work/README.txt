Put finished advertising, packaging, poster, sticker, decal, or display design images in this folder using these names:

work-01.jpg
work-02.png
work-03.webp

The site checks work-01 through work-80 automatically.
Supported formats are jpg, jpeg, png, and webp.

The first 4 images are shown immediately.
If there are more than 4 images, a View all work button appears.
The button changes to Show less work after opening the full list.
